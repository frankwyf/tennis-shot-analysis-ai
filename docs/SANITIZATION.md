# Sanitization and Open-Source Readiness

This repository is intentionally prepared for open-source sharing.

## What was sanitized

- No private video assets are included.
- No personal names, client identifiers, internal ticket IDs, or private paths are included.
- Example data is generated synthetically for deterministic public demos.
- Video mode is optional and runs only on local files provided by the user.

## What remains intentionally generic

- Landmark-based metrics are educational proxies, not medical or professional performance claims.
- The workflow is designed for transparent learning and portfolio demonstration.

## Publisher checklist

1. Confirm no real player videos are committed.
2. Confirm no accidental secrets in notebooks or shell history.
3. Keep all sample artifacts synthetic or user-generated.
4. Keep README and docs aligned with current code behavior.
